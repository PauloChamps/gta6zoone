# Regras de manutenção — GTA6Zoone

1. Não alterar a identidade visual sem solicitação explícita.
2. Não alterar a estrutura global sem autorização.
3. Não reescrever o CSS global para resolver um problema localizado.
4. Não modificar header ou footer durante tarefa não relacionada.
5. Não remover funcionalidades existentes.
6. Não renomear classes sem necessidade.
7. Não reorganizar diretórios sem autorização.
8. Reutilizar componentes existentes.
9. Fazer a menor alteração possível.
10. Verificar o impacto antes de modificar arquivo compartilhado.
11. Preservar desktop, tablet e mobile.
12. Não adicionar frameworks.
13. Não adicionar dependências sem autorização.
14. Não inventar conteúdo de GTA VI.
15. Não alterar arquivos fora do escopo da tarefa.
16. Não refatorar código funcional sem solicitação explícita.
17. Antes de terminar, verificar console e links afetados.
18. Informar exatamente quais arquivos foram modificados.
19. Preservar compatibilidade com GitHub Pages.
20. Ler este arquivo antes de qualquer alteração futura.
